# Smart Task Manager

A simple and interactive task management application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by status
- Filter tasks by priority
- Save tasks using LocalStorage
- Responsive user interface
- Task statistics

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage
- Git & GitHub

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/haris-afzaal/smart-task-manager.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies are required.
